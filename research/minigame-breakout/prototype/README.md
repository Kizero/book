# 浣然一新 · Dust & Dash

一个本地浏览器可玩的清洁战斗原型。小浣熊主角，采用经核查的 Kenney CC0 素材与专用 SVG 清洁器，详见 [素材来源](ASSETS.md)。没有账户、网络埋点或付费接口。

## 打开

在本目录运行：

```sh
python3 -m http.server 4177 --bind 127.0.0.1
```

浏览器访问 [http://127.0.0.1:4177](http://127.0.0.1:4177)。需要通过 HTTP 打开，直接双击 HTML 文件可能因模块加载限制而失败。当前服务只允许本机访问，手机截图和触控测试来自浏览器设备模拟，尚未完成手机真机验证。

## 操作

- WASD / 方向键移动，鼠标指向目标；左键或空格发射。
- 吸入持续开启；没有鼠标指向时，自动瞄准最近怪物。
- 触屏使用左下摇杆移动，右下发射，自动瞄准。
- 按 Esc 暂停；切换窗口或页面隐藏时自动暂停。
- 声音默认关闭，右上角可以打开。

开局从高压弹球、三联散射、泡沫喷射三种清洁器中选一把。吸地面污渍与泥壳积攒弹药，也可以吸入敌方泥弹。至少 20 点弹药可以发射：高压与散射使用当前全部储量；泡沫每次只消耗 20 点，落地留下持续清洁、减速的泡沫。没有弹药也能吸掉泥壳、伤害裸露怪物。

击败怪物触发范围清洁与冲击伤害。清空敌人，或清洁度达到 90%，任一成立即可过关；剩余污渍自动收尾，未击败怪物退场，不计为击杀。共十二关、三个场景主题、十一次随机三选一升级。22 种升级包括穿透、弹墙、返还弹药、清洁鞋、扫地伙伴与减速。过关回一格体力，部分升级可叠加，达到上限后不会再次出现。尚未实现长期局外成长。

## 结构

- `src/content.js`：清洁器、关卡、升级与清洁目标配置。
- `src/assets.js`：素材预加载，加载失败时阻止进入缺图版本。
- `src/engine.js`：固定步长模拟、地面污渍、吸入、弹药、怪物、伤害、关卡和升级。无 DOM 依赖。
- `src/render.js`：场地、角色、粒子、击破冲击和绘制。只消费模拟事件。
- `src/main.js`：输入、HUD、声音、暂停、结果和导出。重开清理输入及视觉状态。
- `tests/engine.test.js`：吸入补弹、泥弹捕获、无弹药攻击、连锁只结算一次、十二关通关、升级、暂停与重开等测试。
- `tests/browser-smoke.cjs`：通过按键、鼠标和触控事件运行浏览器检查，不修改游戏状态；需要本机 Playwright 和浏览器。

```sh
node --test tests/engine.test.js
```

## 本次验收与边界

引擎测试通过；浏览器通过实际输入验证关卡、升级与重开，验证暂停冻结、移动、手机尺寸摇杆移动／松手停止以及无横向溢出。运行摘要与截图保存在 `artifacts/`。自动操作能获胜只说明流程成立，不是玩家体验、商业潜力或设备性能的验证。

手机尺寸采用纵向房间，电脑采用横向房间。当前玩法强度偏向快速体验，花园、工坊、温室采用不同地面和边界布置。尚未接微信／抖音发布、存档、资源分包，也没有用本地浏览器表现推断平台兼容性。

## 第一次试玩关注什么

1. 能否不看说明理解“吸”和“喷”的关系？
2. 吸入与发射是否都值得主动操作，还是其中一个显得多余？
3. 击破时，是否同时感受到打中怪物和场地变干净？
4. 哪一刻觉得乏味、看不清或难以控制？

胜利或失败后可点击“保存这一局的记录”，下载本机 JSON：版本、清洁器、种子、关卡、升级、射击、受伤与击破时间线，以及每关的胜利方式和剩余敌人数。不会自动上传。它用于定位体验问题，不把击杀数或通关速度当作满意度。

### 新增组合装备

开局选一把清洁器，再选泡泡机／静电毛刷／旋转拖把／小鸭／刷盘／回收桶中的一件。六种装备均可在局内升级到 III；试试泡沫主武器 + 静电，或泡泡机 + 小鸭。弹球会引爆泡泡，拖把可以接球再击出。升级界面显示下一等级，场地下方显示激活的组合。

`tests/gadgets-browser.cjs` 检查四种开局装备与手机菜单；`tests/browser-smoke.cjs` 支持 `UPGRADE_PRIORITY=duck,electric,mop,bubble` 走组合构筑路线。测试模块路径与 Chrome 可执行文件由现有环境变量指定。

### 组合试玩与改造道具

开局“本次出发”可切换正常成长或四套预装组合：雷泡运输队、电动洗地风暴、弹球清扫阵、双向回收站。预装组合用于直接体验成型效果，重开会保留套装；切回正常成长只保留自选开局装备。可继续改选主武器与额外开局小帮手。

新增弹簧刷盘、磁力回收桶，以及超大压缩仓、双头吸嘴、回旋喷嘴、泡泡背包四件唯一改造道具。高级连携按等级自动激活；场地下方的配方说明列出条件。新装备和改造均可在正常升级中获得。

回收桶暂存的垃圾及泡泡货物仍计入未清洁量，处理后才完成回收。桶 8 秒到期会自动结算，泡泡到期若有货物会爆开结算。回旋喷嘴只回收存活的弹球，撞怪消失的不会返还弹药。

### 十二关与新捣蛋鬼（2026-09-14）

保留原六关组合，第 7—9 关依次引入冲撞怪、落泥怪、补壳怪，第 10—12 关混合编队，最终双首领。关卡延续花园、工坊、温室三个主题，不是十二套全新地图。每过一关仍只选一次升级，等级上限、出牌池和恢复规则不变。

冲撞锁定方向后预警 0.85 秒，泡泡可打断，泡沫可减速；落泥提前 1.15 秒标出固定落点，离开圈子可躲避；补壳怪每 3.6 秒修补 145 范围内其他活怪的 12 点泥壳，不能超过原上限。落点不属于可吸入的飞行泥弹。

非泡沫垃圾弹穿过泡沫，单颗只强化一次：伤害 ×1.25、半径 ×1.2，命中后携带泡沫到新落点。弹球命中还按装填量扩大局部清洁。过关升级前用底部成果条展示完整地面，点“挑选升级”打开原三选一。

`node tests/campaign-simulation.mjs` 用脚本控制而非强制击杀运行多种构筑；结果写入 `artifacts/campaign-v5.json`。这是可运行性与回归证据，不是人类玩家难度测试。`tests/enemies-preview.html` 为单独的固定渲染检查页，不是游戏入口。

### 花园茶会委托（版本 6）

前四关组成一份茶会清洁委托：入口垃圾堆、左右花圃、备餐区、翻桶大王。归一化手工位置适配横向／纵向场地；敌人数与每关升级时点沿用原规则。第四关首领周期甩出六处有预警的泥团，清洁达标或杀光仍能过关。

前四关统一使用手绘庭院；原先的旧拼装敌人改用手绘主体、不同配饰及受击形变。清理后显露花朵，收工显示蝴蝶，第四关完成后摆出茶点、颁发叶子徽章。完成地点与徽章保存在本机 localStorage；不会上传，不增加永久数值。当前不保存进行中的战局。

打开声音后，吸尘器电机声随装填与吸入变化；发射、破壳、连携和完成有分层短音。声音默认仍关闭。`npm test` 包含委托记录测试；`tests/commission-preview.html` 只用于首领及收尾画面检查。

### 吸喷反馈与收工演出（版本 7）

持续吸入与弹球重击现在使用不同的受击形变／亮度。发射有喷口闪光、角色后坐和短拖尾；泡沫裹弹、拖把接力、爆泡在发生位置有短提示，连续击破显示“连续清除”。提示限频、过期清除，暂停与换关不会残留。

升级卡根据当前装备补充配合方式；第四关首领有独立名字、生命／泥壳显示与入场提示。声音改为过滤气流、电机与短促低频喷射组合，保留关闭声音开关。第四关清洁结束后，原庭院渐变到新增手绘茶会背景，替代几何茶桌。素材和最终提示词见 `assets/illustrated/tea-courtyard-v2-prompt.md`。
