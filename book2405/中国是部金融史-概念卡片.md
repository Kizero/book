# 概念卡片：三千年金融史的核心判断工具

> 遇到一个历史或经济情境时，快速定位"这属于哪种模式"。

---

## 卡片1：政权体检清单

```
当判断一个政权的健康状况时，查四个指标：

□ 土地分配  → 大多数农民有自有地？还是大量佃农/流民？
□ 货币状态  → 足值/稳定？还是减重/虚值/通胀？
□ 官僚控制  → 皇权/政府能约束官员？还是官员各自为政？
□ 社会流动  → 底层有上升通道（科举/商业/军功）？还是门阀垄断？

结论：
- 四项全绿 → ✅ 盛世健康（如文景之治）
- 前三绿+红 → ⚠ 繁荣但脆弱（如开元盛世后期）
- 两绿两红 → 🔴 中期危机（如汉武帝晚年）
- 全红 → 💀 崩溃边缘（如东汉末年/唐末）
```

## 卡片2：三种掠夺模式速查

```
政府缺钱时的三种操作，按隐蔽程度排序：

1. 盐铁专卖（最隐蔽）
   操作：垄断必需品流通，加价出售
   民众感受：不明显（"不是税，是买东西"）
   腐败风险：高（官商勾结）
   典型案例：管仲→桑弘羊→第五琦

2. 铸币减重/虚值（次隐蔽）
   操作：降低货币金属含量或夸大面值
   民众感受：逐步感知（"钱越来越不值钱"）
   腐败风险：更高（私铸猖獗）
   典型案例：汉荚钱→唐乾元重宝

3. 直接加税/卖官（最赤裸）
   操作：增加税种税率/明码标价卖官
   民众感受：立即感知（"朝廷在抢钱"）
   腐败风险：极高（官就是买来的）
   典型案例：汉灵帝卖官→唐德宗宫市

选择规律：能选隐蔽，绝不选赤裸——因为赤裸会立即引发反抗。
```

## 卡片3：货币信号灯

```
货币状态 → 政权状态

✓ 足值货币 + 稳定币值 → 政权健康，尊重市场规则
⚠ 出现减重货币 → 财政紧张，政府开始隐性掠夺
🔴 虚值货币（当十/当五十） → 财政危机，政府已不顾一切
💀 民间大量私铸 + 以物易物 → 货币信用崩溃，政权即将瓦解

例外：
- 隋五铢（2.42g）实际是"最优减重"——市场竞争的结果，不是掠夺
- 判断标准：央行/政府主动减重 = 掠夺；市场自发减重 = 交易成本优化
```

## 卡片4：均田制→崩溃的时间线

```
条件具备 → 均田（初期）
  ↓
人口增长 → 土地稀缺
  ↓
天灾/徭役 → 小农被迫卖地
  ↓
官僚收购 → 土地集中
  ↓
税基萎缩 → 财政危机
  ↓
政府加码 → 更多小农破产
  ↓
流民潮 → 社会崩溃
  ↓
大战乱 → 人口锐减＋土地重新无主
  ↓
回到起点
```

**这个循环，中国三千年没有打破。**

## 卡片5：好市场 vs 坏市场（快速判断）

```
场景：你去一个市场做生意

好市场：
- 不认识人也能做 → 规则透明
- 合同有保障 → 违约可追责
- 政府中立 → 不偏向任何一方

坏市场：
- 必须认识人才能做 → 关系大于规则
- 合同看对方心情 → 违约没处说理
- 政府本身就是最大的生意人 → 裁判兼球员

中国封建社会始终是"坏市场"。
这不是发展阶段的落后，是权力结构的必然。
```

## 卡片6：历史上的"第三种选择"尝试

```
三元结构→死结，但历史上有人试过破解：

▪ 周厉王的"专利" → 想从诸侯手里收税 → 被推翻（早了1000年）
▪ 王莽的改革 → 想用复古理想打破豪强 → 灾难
▪ 隋文帝的科举+三省+禁令 → 最接近成功 → 但炀帝毁掉
▪ 唐玄宗的"限购令" → 强硬禁止土地买卖 → 死后崩溃
▪ "二王八司马"改革 → 理想主义小人物 → 被节度使碾压

共同点：所有尝试都以失败告终。
不是改革者无能，是结构性力量太强。

启示：在结构不变的前提下修补，只换来"结构性反弹"。
```

## 卡片7：金融是权力的影子

```
读完全书得到一个认知工具：

在任何社会里，金融体系的形态 = 权力结构的投影

皇权至上 → 铸币权垄断（货币为统治服务）
官僚主导 → 金融资源向特权阶层集中
权力受约束 → 金融市场可自发发展（如光荣革命后的英国）

工具用法：
遇到一个国家的金融体系，先别分析利率汇率——
先分析"权力结构决定金融资源的流向"。
中国三千年经验反复证明：金融乱象的表层是经济问题，深层是权力问题。
```
