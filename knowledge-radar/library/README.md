# Local reading library

这里保存已经确认可直接阅读、且与信息雷达候选对象对应的材料。

- 优先保存原作者已进入公版或明确授权传播的版本；
- 原文、译文和第三方注释的版权状态分别判断；
- 文件来源、许可说明和内容完整性记录在相应的 `records/` 中；
- 收到用户反馈后，可以只保留链接而不长期保存本地副本。
