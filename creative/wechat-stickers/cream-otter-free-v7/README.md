# 奶獭慢半拍 · 第七版

16 张免费微信表情的本地草稿，尚未提交审核。

本版保留已认可的角色画面，重新剪辑动作顺序与曝光时间。预备和反应有停留，发力和失衡短促；结尾落到明确的安定姿势，再从同一姿势开始下一轮。晚安保持闭眼，无语保持半垂眼，不再用恢复精神的画面重置情绪。特效在长停顿前散去。

首尾一致只解决循环接缝，不能自动保证全部动作自然。现有素材仍是关键姿势组合，没有为大幅转身补画完整中间帧。

- `preview/index.html`：16 张预览、上版对照、特效开关和逐帧查看。
- `export/gif`：240 × 240 GIF，每帧以 40 ms 为单位，包含无特效版。
- `source/piskel`：五层可编辑工程，25 FPS 重复曝光帧与 GIF 同步。
- `source/input-piskel`：本次剪辑使用的原始五层画面。
- `edit-plan.json`：原始姿势编号与停留时间，支持重排或删减。
- `docs/timing-notes.md`：逐张调整说明。
- `docs/timing-qa.json`：编码、透明边距、首尾一致和源角色保留检查。

复现：安装 Pillow，执行 `python3 tools/build.py` 后执行 `python3 tools/package.py`。预览目录使用普通 HTTP 静态服务器。

字体为 ZCOOL KuaiLe，许可随附于 source/fonts。角色为本项目既有原创图像，前版通过 AI 绘制关键姿势；本版通过分层时间轴剪辑，没有重新生成角色图。
